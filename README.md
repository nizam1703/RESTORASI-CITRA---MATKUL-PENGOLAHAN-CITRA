# RESTORASI-CITRA---MATKUL-PENGOLAHAN-CITRA
ISI SOURCE CODE
- Import gambar dari file yang sama
- Mengubah gambar 3 channel menjadi 1 channel 8 bit (Grayscale)
- Menambahkan noise Salt & Pepper dan Gauissian pada citra Grayscale
- Mengurangi noise dengan filter Min, Max, Median dan Mean
- Menghitung nilai MSE-nya
- Menyimpan semua gambar dalam direktori yang di buat (result)
